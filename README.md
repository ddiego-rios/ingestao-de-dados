# Ingestão de Dados

Projeto desenvolvido em aula no âmbito da formação de **Ingestão de Dados**.

Este repositório reúne trabalhos práticos desenvolvidos durante as aulas, com ficheiros Power BI utilizados para exploração, transformação e análise de dados.

## Sobre o autor

Sou aluno e estudante de **Análise de Dados (IEFP)**, com interesse em Python, SQL, Power BI, ETL, modelação, estatística aplicada e Business Intelligence.

## Conteúdo

Os ficheiros deste repositório correspondem aos exercícios, avaliações e projetos realizados durante a unidade de formação. A pasta original `10799` foi identificada neste projeto como `10798`, conforme a organização solicitada.
